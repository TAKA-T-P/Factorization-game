# 因数×展開 FIGHT!

中学3年生の数学「展開」「因数分解」「平方根」を、制限時間内にテンポよく解いて段位を目指すブラウザゲームです。
はじめて単元を学ぶ生徒のために、アニメーションとミニ問題で基礎から学べる **「はじめての因数×展開講座」（チュートリアル）** も入っています。

- 公開URL：https://taka-t-p.github.io/Factorization-game/
- 学習の流れ：**考え方を知る → アニメーションで理解する → 自分で解いてみる → ゲームで習熟度を高める**

HTML・CSS・JavaScript だけで動作し、ビルドは不要です。

## 遊び方（ゲーム）

1. `index.html` をブラウザで開きます（PC・スマートフォン対応）。
2. タイトル画面で **制限時間**（1分 / 3分）と **難易度**（ノーマル / ハード）を選びます。
3. 3つのモードから1つを選んでスタートします。各モード横の「？」ボタンで、公式や解き方の解説を確認できます。
4. カウントダウン後、表示された式に対して正しい選択肢をタップして解答します。

### ゲームモード

| モード | 内容 | ハードモードで追加される問題 |
| --- | --- | --- |
| 展開ラッシュ | `(x+a)(x+b)` などを展開し、xの係数と定数項を選ぶ | `(x+ay)(x+by)`、`(cx+d)²`、`(cx+dy)²`、`(cx+d)(cx−d)`、`(cx+dy)(cx−dy)`、共通因数 `ax(bx±c)` など |
| 因数分解ラッシュ | `x²+px+q` を `(x+a)(x+b)` の形に因数分解する | 上記の逆パターン（`c²x²−d²` など）、共通因数でくくる問題 |
| 平方根ラッシュ | `√n` を `a√b` の形に簡単にする | 分母の有理化（`ab/√b = a√b`） |

ハードモードでは画面のテーマ色が変わります。

### ルール

- **得点**：正解ごとに `(10 + コンボ数)²` 点。不正解は −200 点（0点未満にはなりません）。
- **コンボ**：正解すると「コンボ継続ゲージ」が表示されます。ゲージが尽きる前に次の問題に正解するとコンボが続きます。コンボが伸びるほどゲージの減りが速くなります。
- **ヒント**：1問に10秒以上かかると「ヒント」ボタンが現れ、正解の選択肢を1つ（ハードモードでは2つ）ハイライトします。
- **最終問題**：残り時間が0になると、そのとき出ている問題が「最終問題」になります。20秒以内に解答しないと時間切れ（不正解扱い）です。

### 結果画面

- **段位**：10級〜1級、初段〜十段、皆伝の21段階。
  `(正解数 − 不正解数 + コンボボーナス) ÷ モードごとの係数` で決まります。コンボボーナスは `(最大コンボ数 − 1) × 0.1`（上限 0.9）です。
- **戦績**：正解数・不正解数・最大コンボ数。
- **スコア**：最終スコアとハイスコア。ハイスコアはモード・制限時間・難易度の組み合わせごとにブラウザの `localStorage` に保存されます。
- **問題履歴**：出題された問題・正解・正誤・解答時間の一覧。

### その他の機能

- 効果音のON/OFF切り替え（タイトル画面右上）。効果音は Web Audio API で生成しています。チュートリアルの効果音もこの設定に従います。
- タイトル画面左上から「KEC数学科ラボ」ポータル（https://taka-t-p.github.io/math-app-portal/ ）へ移動できます。
- プレイ中の「リトライ」「戻る」ボタン。

## はじめての因数×展開講座（チュートリアル）

タイトル画面の **「📘 はじめての因数×展開講座」** から始めます。公式をまだ知らない生徒でも、動きを見ながら一歩ずつ学べます。

### 講座とレッスン

3つの講座があり、それぞれ5レッスン（全15レッスン）です。前のレッスンを終えていなくても、どのレッスンからでも始められます。

**展開マスター講座**（青）

| | レッスン | 内容 |
| --- | --- | --- |
| 1 | 分配法則って何？ | `2(x+3) = 2x+6`。外の数を中の **すべての項** にかける |
| 2 | 4つのかけ算をマスター！ | `(x+2)(x+3)` を4つのかけ算で展開し、同類項をまとめて `x²+5x+6` にする |
| 3 | 公式① x²+(a+b)x+ab を使おう！ | 「たして まん中、かけて 最後」。`(x+4)(x−3)`、`(x−3)(x−4)` などマイナスの数も |
| 4 | 2乗の公式・和と差の公式を使おう！ | `(x+a)²`、`(x−a)²`、`(x+a)(x−a)` が4つのかけ算から生まれることを確かめ、使い分ける |
| 5 | 発展する展開に挑戦！ | `(2x+3)²`、`(2x+3)(2x−3)`、`(x+2y)(x+3y)`、`2xy(3x−y)` など（ハードモード対策） |

**因数分解マスター講座**（緑）

| | レッスン | 内容 |
| --- | --- | --- |
| 1 | 因数分解は展開の逆！ | 展開と因数分解を行き来するアニメーション |
| 2 | 足して・かけて探そう！ | 足して `p`、かけて `q` になる2つの数を選ぶ |
| 3 | 2乗の公式を逆に使おう！ | `x²+6x+9 = (x+3)²`、`x²−16 = (x+4)(x−4)` |
| 4 | プラス・マイナスに注意！ | `x²−x−6 = (x+2)(x−3)` など、符号のルール |
| 5 | 共通因数と発展問題！ | `3x²+6x = 3x(x+2)`、`4x²−9`、`4x²+12x+9`、`y` をふくむ式（ハードモード対策） |

**平方根マスター講座**（紫）

| | レッスン | 内容 |
| --- | --- | --- |
| 1 | 平方根って何？ | 9の平方根は `3` と `−3`、`√9 = 3`（√ はプラスの方だけ）のちがい |
| 2 | √の中を簡単にしよう！ | `√12 = √(4×3) = 2√3` |
| 3 | 平方数を見つけよう！ | いちばん大きい平方数を見つけて一度で簡単にする（`√72 = 6√2`） |
| 4 | いろいろな√に挑戦！ | `√50`、`√75`、`√98` など |
| 5 | 分母の有理化に挑戦！ | `3/√3 = √3`、`6/√2 = 3√2`（ハードモード対策） |

### レッスンの進め方

各レッスンは4つのSTEPでできています。

1. **考え方を知ろう**：短い解説を1画面に1ポイントずつ読む
2. **動きを見て理解しよう**：式の変形を1コマずつ見る。かけ合わせる項とその結果は同じ色・同じ下線で示し、矢印で結ぶ
3. **自分で解いてみよう**：ミニ問題（2〜4問）。時間制限なし・得点や段位には影響しない
4. **レッスン完了**：「次のレッスンへ」「もう一度復習する」「講座一覧へ戻る」（最後のレッスンでは「次のレッスンへ」は出ない）

操作のポイント：

- 画面下の「← 戻る」「次へ →」で移動します（PCでは ← → キーも使えます）。アニメーションの途中でもすぐ切り替えられます。
- アニメーションは「↺ もう一度見る」でいつでも最初から見直せます。
- ミニ問題は、正解するまで次へ進めません。まちがえると、選んだ答えに合わせたヒントが出て、何度でもやり直せます（答えを自動で表示することはしません）。「📖 解説を見直す」で STEP 1 に戻れます。
- 一度完了したレッスンの復習では、ミニ問題をスキップできます。
- 上部の「← レッスン一覧」「タイトル」から、いつでも抜けられます。
- 端末の「視差効果を減らす（動きを減らす）」設定がオンのときは、アニメーションの動きを止めて表示します（内容は同じです）。

ミニ問題の形式：

| 形式 | 例 |
| --- | --- |
| 選択問題（複数選択あり） | `(x+2)(x+3)` を展開すると？／72を割り切る平方数をすべて選ぼう |
| 数の組を選ぶ問題 | 足して5、かけて6になる2つの数を選ぶ。選ぶと足し算・かけ算の結果が ✓／✗ つきで表示される |
| 手順選択問題 | `√18` を簡単にするとき、まず見つける平方数は？ |
| 穴埋め問題 | `(x+3)² = x² + □x + 9` の□に入る数を選ぶ |

### 「？」解説との使い分け

- **「？」解説（クイック解説）**：公式を思い出したい生徒向け。これまでどおりの内容です。
- **はじめての因数×展開講座**：初めて学ぶ生徒向け。具体例とアニメーション、ミニ問題で基礎から学びます。

「？」解説の一番下にある「基礎からじっくり学ぶ → チュートリアルへ」から、その分野のレッスン一覧へ移動できます。

### 学習進捗の保存

進捗はブラウザの `localStorage` に、キー `factorizationFight.tutorial.v1` で保存されます。

```json
{
  "version": 1,
  "lessons": { "expansion-01": true, "factorization-01": true },
  "lastLesson": "factorization-02",
  "lastStep": 2,
  "updatedAt": "2026-10-31T09:00:00.000Z"
}
```

- 保存するもの：各レッスンの完了状態、最後に学習したレッスンとSTEP（「続きから」に使う）、最終更新日時。
- ハイスコア（`highScore_<モード>_<秒数>_<難易度>`）とは別のキーなので、既存の記録には影響しません。
- 保存データがない・壊れている場合は、空の進捗として正常に起動します。
- プライベートブラウズなどで保存できない環境でも、進捗を保存しないまま学習できます。
- 進捗は端末・ブラウザごとに保存されます（別の端末には引き継がれません）。

### 設計メモ

- **ES Modules ではなく通常の `<script>` で読み込んでいます。** `index.html` をダブルクリックで直接開いても（`file://`）動くようにするためです。ゲーム本体は旧 `index.html` のコードを責務ごとにそのまま移したもので、関数や変数はこれまでどおりグローバルです。`index.html` の `<script>` の順番は変えないでください。
- チュートリアルのコードは即時関数で包み、`window.Tutorial` だけを公開しています（ゲームの関数名と衝突しません）。
- 教材の文章・例題・正解・ヒントは `js/tutorial/lessons/` のデータにまとめ、表示の処理から分けています。

Node.js 24.15 以上（22 系なら 22.22 以上）が必要です。

```sh
npm install
npm test
```

テストは [jsdom](https://github.com/jsdom/jsdom) 上で実際の `index.html` とスクリプトを読み込んで動かします。

| `tests/unit/lessons.test.js` | 教材データの整合性と数学的な正しさ。解説・アニメーション・文章中のすべての等式、選択肢の正誤、数の組の一意性、穴埋めの正解・不正解 |
| `tests/unit/tutorial.test.js` | 全15レッスンを（一度まちがえながら）最後まで進められること、ヒント表示、進捗の保存・再開、壊れた保存データ、保存できない環境、「？」解説からのリンク、動きを減らす設定 |

## 変更履歴

- ハードモードの共通因数パターン（展開の `ax(bx±c)` など、因数分解の `abx²±acx` など）で、「ヒント」ボタンを押しても選択肢がハイライトされなかった不具合を修正しました。展開は正解の2つ、因数分解は正解の1つがハイライトされます（ほかのモード・パターンのヒントは変わりません）。

## 教材データの書き方

レッスンは `js/tutorial/lessons/*.js` にデータとして書きます。レッスンを追加したら `npm test` で数学的なチェックを通してください。

```js
{
    id: 'expansion-01',                 // 講座ID-2桁の番号（進捗の保存に使うので変えない）
    title: '分配法則って何？',
    goal: '…を理解する',
    learn: [                            // STEP 1：1ページに1ポイント
        { heading: '…', text: ['段落', '段落'], math: ['2(x+3) = 2x+6'], after: ['…'], point: '…' },
    ],
    animation: {                        // STEP 2：コマごとに式全体を書く
        title: '…',
        frames: [
            { lines: ['[[2|1*|k]]([[x|2|a]]+3)', '= [[2x|2|r1]]'], links: [['k', 'a', 2]], caption: '…' },
        ],
    },
    problems: [ /* STEP 3：下の4形式 */ ],
    clearMessage: '展開の基本がわかったね！',
}
```

**数式の書き方**（`math`・`lines`・選択肢の `label` など。文章の中では `$…$` で囲む。`**…**` は強調）

| 書き方 | 意味 |
| --- | --- |
| `[[2x\|1\|r1]]` | 色付きの項。`1`〜`6` が色（色ごとに下線の形も変わる）、`*` を付けると枠で囲む、`~` で打ち消し線。3つ目はアニメーションの矢印用ID |
| `√{12}` | 根号（中身に横棒） |
| `{{3\|\|√{3}}}` | 分数（分子と分母） |
| `-` | 表示では `−` になる。英小文字は斜体になる |
| `{ m: '式', note: '補足', cls: 'result' }` | 行に補足を付ける。`cls` は `result`（強調）・`muted`（うすく）・`small` |
| `{ arrow: 'まとめる', up: true }` | 行の間の矢印（`up` で上向き） |
| `{ arrow: '展開', back: '因数分解' }` | 行の間に、向きが逆の矢印2つを横に並べる（↓展開　↑因数分解） |

- 新しく現れた行・項は自動でアニメーションします。`links: [[項ID, 項ID, 色]]` で項どうしを矢印で結びます。
- `=` でつながった式は、テストで「両辺が等しいか」を自動チェックします。作りかけの式は `= x²` のように `=` から始めます。

**ミニ問題の形式**

```js
// A. 選択問題（multiple: true で複数選択。hintMissing は選び足りないときのヒント）
{ type: 'choice', question: '$3(x+2)$ を展開すると？', verify: { expr: '3(x+2)' },
  options: [ { label: '3x+6', correct: true }, { label: '3x+2', hint: 'まちがえた理由に合わせたヒント' } ],
  explain: '正解したときの短い解説' }
// 文章の選択肢は label のかわりに text。値は等しいが答えの形として不十分な選択肢には sameValue: true

// B. 数の組を選ぶ問題（足して sum、かけて product）
{ type: 'pair', question: '…', sum: 5, product: 6, numbers: [1, 2, 3, 4, 5, 6], answer: [2, 3],
  result: 'x²+5x+6 = (x+2)(x+3)', explain: '…' }

// C. 手順選択問題（work に途中の式を表示。中身は選択問題と同じ）
{ type: 'step', question: '…', work: ['√{18} = √{□×□}'], verify: { squareDivisorsOf: 18 }, options: [ … ] }

// D. 穴埋め問題（[?0] [?1] が□。hints は選んだ数ごとのヒント）
{ type: 'fill', question: '…', template: '(x+3)² = x²+[?0]x+9',
  blanks: [ { answer: '6', options: ['3', '6', '9', '12'], hints: { '3': '…' } } ], explain: '…' }
```

`verify` は選択肢の正誤をテストで数学的に確かめるための指定です：`expr`（問題の式と等しいか）、`squareDivisorsOf`・`largestSquareDivisorOf`（割り切る平方数）、`perfectSquares`（平方数か）、`squareTrinomial`（`(x+k)²` の形か）、`makesIntegerWith`（かけると整数になるか）。式の選択肢だけの問題には必ず付けてください。

## GitHub Pages での公開

1. 変更を `main` ブランチに push します。
2. リポジトリの **Settings → Pages** で、**Deploy from a branch**・ブランチ `main`・フォルダ `/ (root)` になっていることを確認します。
3. 数分後に https://taka-t-p.github.io/Factorization-game/ で、ゲームとチュートリアルの両方が使えます。

読み込みはすべて相対パスなので、`/Factorization-game/` のようなサブパスでもそのまま動きます。`tests/`・`package.json` は公開されますが、ゲームの動作には使われません（`node_modules/` は `.gitignore` で除外しています）。

## 調整用パラメータ

ゲームバランスは次の箇所で調整できます。

- `js/ranks.js` の `getRankCoefficient()`：段位計算の係数（モード・時間・難易度別）
- `js/game.js` の `getGaugeSpeedMultiplier()`：コンボゲージの減少速度
- `js/game.js` の `comboGaugeDuration`：コンボゲージの基本時間（初期値 10秒）
- `js/ranks.js` の `ranks`：段位の名称一覧
- `js/main.js` の `catchphrases`：タイトル画面にランダム表示されるキャッチコピー
